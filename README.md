# Netflix Sala 5

## Descripción del Proyecto

Este proyecto consiste en la creación de un clon de la página principal de **Netflix México** utilizando tecnologías web como HTML, CSS y Bootstrap. El objetivo fue replicar el diseño y la estructura visual de la plataforma para poner en práctica conceptos de desarrollo web responsivo y trabajo colaborativo.

**Plataforma clonada:** Netflix  
Sitio original: https://www.netflix.com/mx/

## Componentes Bootstrap Utilizados

- Navbar
- Botones
- Carrusel 
- Sistema Grid
- Contenedores 
- Tarjetas 
- Acordeón 
- Forms
- Droppdowns
